# 🔮 Virtual Oracle

Virtual Oracle is a statistical virtual-football prediction and backtesting tool.

## Features

- Home / Draw / Away predictions
- Probability percentages
- Confidence score
- Experimental correct-score prediction
- Historical CSV backtesting
- Screenshot upload
- Mobile-friendly interface

## GitHub Structure

The repository should look like this:

virtual-oracle/
│
├── app.py
├── requirements.txt
└── README.md

## Run Locally

Install the requirements:

pip install -r requirements.txt

Then run:

streamlit run app.py

## Deployment

Deploy the project using Streamlit Community Cloud.

Select:

Main file:
app.py
